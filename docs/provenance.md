# Source provenance and publication boundary

The source workspace was `razorpay-buildathon`, with no Git remote configured, branch `main`, and base commit `4bc0bf4` (`fix: stabilize serial commerce baseline and freeze search contract`). It contained modified tracked files, substantial untracked HPC/application work, ignored environment files, generated catalogues, caches and local artifacts. The recorded Git author was ADITHYA-SANJEEVI. The owner identified this as their project and authorized publication subject to audit.

The root README described Razorpay Buildathon; modules and catalogues used Studio naming. No source evidence established Quarry as the existing name of the whole application. This release adopts Quarry for the selected HPC commerce-search subsystem and records that rename explicitly.

The source snapshot was assembled separately. No reset, clean, bulk staging, original-history push, database change or payment mutation was performed. The original workspace was preserved. Only the reviewed new repository's explicit file list was staged. The original history was excluded from publication rather than certified safe.

## Included

- Deterministic intent parser/normalizer, hard constraints, relevance primitives, commerce ranker, adequacy and preview compiler.
- HPC immutable contracts/snapshots, context generation, scalar feature workers, global fusion, bounded runtime, tracing, experiment storage/runner, quality and analysis modules.
- The existing HPC catalogue/experiment HTTP router and its transitive source/type dependencies.
- Original fictional small evaluation fixtures, catalogue generator and regenerated checksum manifests.
- Focused original engine/catalogue/experiment tests, plus release HTTP, speaker regression and complete-digest parity tests.

`source-manifest.json` records the initial extraction paths/hashes and flags adaptations. It includes untracked source absent from the base commit. The final published Git tree supplies the final content identity. Original extraction hashes are not a claim that later release fixes are byte-identical.

## Release adaptations

- Replaced the broad application entry point with the offline HPC router and a small asset-free workbench. The original Next.js application is excluded because its authentication/payment/product-media dependencies exceed this release boundary.
- Replaced the payment/authentication golden harness dependency with its query cases and focused complete-search digest parity tests. Kept pure-feature, failure, concurrency, scheduling and experiment tests.
- Added `speaker` to the controlled role vocabulary, using existing canonical speaker facts and existing bounded fuzzy normalization; added regression coverage.
- Extended hard-exclusion conflict evaluation to canonical role facts after a regression demonstrated that `speaker without speaker` still returned speakers.
- Added pinned dependencies, reproducible setup, documentation, licence, and genuine screenshots of this workbench.

The original relevance reuse audit describes techniques derived from the author's Aastrika course-search project (the same owner's public Search-Optimisation repository). This is self-authored lineage, not a claim of externally licensed commerce data. No Aastrika domain assets, maternal-health vocabulary, model files or datasets were imported for release. Code-level algorithms such as BM25 and RRF retain their standard identities; dependencies remain separately licensed.

## Excluded

The original `.git`, environment files, API credentials, local databases, receipts, shopping ledgers, private logs, generated JSONL, archives, local launchers, unrelated Buildathon/merchant/voice/auth/payment endpoints, original presentation assets, externally hosted product photography, caches, virtual environments, browser state, and GitHub Actions workflows are outside the published tree. No data was copied from Downloads or Interlock.

Retained ORM models and order schemas are dependency scaffolding for original contracts. They do not expose checkout, create live orders, or require a database. Provider settings/adapters remain dormant source; the release uses `FallbackIntentParser` and deterministic lexical scoring.

The synthetic generator is authored source with a fixed seed and fictional specifications. The small evaluation fixtures also contain authored fictional products. There is no redistributed marketplace or Kaggle product dataset. The MIT licence covers the author's code, synthetic generation/fixtures, release UI and documentation. Dependency distributions, their data files and any future third-party assets retain their own terms.
